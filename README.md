## 📌 Overview
This repository contains Experiment 5 of the Web Development Lab curriculum:
- Asynchronous JavaScript using `async/await` and the native `fetch()` API.
- Live Open-Meteo REST API consumption with integrated geocoding coordinates lookup.
- Real-time meteorological data rendering: temperature, wind speed, and direction.
- User experience features including city quick-tags, loading spinner, and responsive cards.
